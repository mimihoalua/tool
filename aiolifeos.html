Chương 1: Kiến Trúc Cốt Lõi

Hệ thống 5 Giao diện (Multi-Seasons Theme)

Loại bỏ hoàn toàn Dark/Light tĩnh. Thay vào đó là ma trận CSS Variables xoay vòng 5 trạng thái rực rỡ: Mặc định (Indigo), Chanh (Lemon), Cam (Orange), Hồng (Rose), Ngọc (Mint).

Trí tuệ nhân tạo NLP V29

Bóc tách tự do ngôn ngữ tiếng Việt. Sửa lỗi đứt gãy tương lai, gắn cờ ưu tiên !gấp tự động phân luồng dữ liệu.

Cơ sở dữ liệu (2 Lớp Hybrid)

Lớp 1 (Offline): localStorage - Lưu tại máy, chống trễ mạng, nạp siêu tốc.
Lớp 2 (Cloud): Firebase Firestore Real-time, phân giải xung đột bằng Timestamp Object.

Cơ chế Auto-Heal & Fallback

Bảo vệ DOM tuyệt đối. Nếu Google TTS từ chối kết nối, API lập tức bẻ lái (Fallback) sang bộ đọc SpeechSynthesis nội bộ. Nếu Firebase gửi mảng rỗng do lỗi sync, Local State lập tức đẩy ngược dữ liệu bảo toàn.

Bảng Phong Thần (Cảnh Báo Lỗi Ngầm)

Ghi nhận lại những sai lầm tàn khốc nhất do tư duy dev "tay nhanh hơn não", lười biếng và không hiểu bản chất môi trường thiết bị di động.

1. Lỗi Đứt Gãy Dây Chuyền (N/A Profile)

Tuyệt đối KHÔNG bọc try/catch tổng vào các hàm khởi tạo biến Global hoặc cắt xén các hàm cơ sở (như setHtml). Nếu một hàm chết, toàn bộ code phía dưới sẽ ngừng chạy, biến PROFILES không được nạp, gây lỗi hiển thị N/A và treo vĩnh viễn màn hình đăng nhập.

2. Lỗi Form Reload (Trang tự F5 mất dữ liệu)

Bỏ quên e.preventDefault() ở thẻ <form id="form-pc">. Khi bấm Enter, trình duyệt tự động thực thi GET request làm reload toàn bộ trang web. Hậu quả: Dữ liệu bay hơi, đứt kết nối Firebase.

3. Bệnh "Hồn Trương Ba, Da Hàng Thịt" (PWA Manifest)

Dùng chung file manifest.json của dự án cũ vào dự án mới. Hậu quả: Cài LifeOS nhưng Icon và Tên hiển thị là Shop Hoa, bấm vào mở nhầm trang đích do sai start_url.

4. Dao Mổ Bò Giết Gà (Lỗi Xóa Trắng Dữ Liệu)

Dùng localStorage.clear() để dọn rác nhạc, kết quả là quét sạch luôn Nhiệm vụ và Vault của người dùng. Cần phải kết hợp Lưỡi Dao Mổ (removeItem đúng Key nhạc) và Máy Hút Bụi PWA (caches.delete toàn bộ API & Service Worker).

5. Cái Chết Của Nút Share & Lời Thề Promise

Truyền sai tham số text vào Web Share API làm Zalo/FB nuốt lỗi AbortError. Bỏ qua Promise .then() của navigator.clipboard.writeText làm lệnh chết ngầm trên iOS nhưng Toast vẫn báo lừa dối "Thành công".

Lõi Kỹ Thuật Sinh Tử (V29)

The Iron Lock (Chống Data Race)

Khi thiết bị đang Push dữ liệu lên Cloud, bật cờ window._pendingPush = true. Trạng thái này sẽ như một tấm khiên, từ chối mọi Snapshot cũ dội về từ Firebase trong lúc mạng đang truyền tải, ngăn chặn việc dữ liệu cũ đè lên dữ liệu mới.

Đồng bộ Vector Clock

Push Flow: Lấy Date.now() lưu Local. Tẩy sạch undefined. Ném nguyên khối lên Firebase cùng updatedAt.

Pull Flow: Kéo Snapshot, ép kiểu cloudTime = c.updatedAt.toMillis(). Nếu cloudTime > localTime ➔ Cập nhật DOM. Nếu localTime > cloudTime (Firebase dội lại Snapshot chậm) ➔ Bỏ qua, lập tức gọi lại pushAll() đè ngược bản Local lên Cloud bảo vệ dữ liệu!

Hệ thống X-Quang Audio 3 Lớp

  • Mỏ Neo 30 Phút: Phát ngầm silence_30min.mp3 để giữ WakeLock cho CPU, chống Doze Mode.
  • Dynamic Audio Ducking: Khi có báo thức, lưu lại volume hiện tại, bóp cổ nhạc nền xuống 20%. Đọc TTS xong nhả lại 100%. Tránh âm thanh đấm nhau.
  • JIT Pre-Caching: Ở mốc đếm ngược 30 giây cuối, ép thẻ Audio tải trước Link Google TTS vào RAM. Bypass ORB bằng meta referrer="no-referrer".

Chương 4: The Perfect Loop (Bí ẩn Đồng bộ)

Hệ thống đã vượt qua bài test áp lực "Infinite Radar 10 Rounds" của Sentinel V15 với độ trễ trung bình không tưởng: 256.03 ms. Dưới đây là 3 trụ cột kỹ thuật đảm bảo sự hoàn hảo này.

1. Cờ Chấp Thuận (Phase 0.5)

Playwright buộc phải chờ biến window.cloudSyncCompleted === true bật lên trên cả 2 máy (PC/Mobile) để đảm bảo Firebase đã Pull xong dữ liệu cũ, tránh ghi đè (Race Condition) ngay giây đầu tiên.

2. Mô Phỏng Nguyên Tử

Loại bỏ hành vi .fill() và .click() cơ học dễ gây "Silent Fail" ở các UI Framework. Sử dụng press_sequentially() kết hợp phím Enter để đánh thức toàn bộ Event Listeners của DOM.

3. Định Vị Mềm (Smart Locator)

Script test không còn "mù quáng" tìm thẻ <li> cứng nhắc. Bám sát cấu trúc DOM V29 bằng get_by_text() và nhận diện trạng thái gạch bỏ qua class .opacity-60 của TailwindCSS.

7 Quy Tắc Vàng Sinh Tử (Tuyệt đối tuân thủ)

Bất kỳ ai chạm vào mã nguồn V29 đều phải thuộc lòng 7 nguyên tắc sống còn sau đây. Cấm vi phạm!

1. Pháo Đài Offline (Chống ORB/404)

Đường dẫn tương đối ./ trên GitHub Pages gây lỗi tải nhầm trang 404 HTML thành file JS gây crash toàn bộ hệ thống. Bắt buộc dùng đường dẫn tuyệt đối /tool/filename.js.

2. Thanh trừng "Undefined"

Firestore sẽ ném lỗi Unsupported field value: undefined và từ chối lưu. Bắt buộc phải chạy vòng lặp delete cleanT[key] trước khi set().

3. Cấm Push Lúc Khởi Động

Tuyệt đối KHÔNG ĐƯỢC gọi this.pushAll() trong hàm init() để tránh thiết bị mới mở đè bẹp dữ liệu của thiết bị khác trên Cloud.

4. Đồng Hồ Vector & toMillis()

Xóa bỏ hoàn toàn cờ `cloudSyncCompleted` cũ. Tranh chấp giải quyết 100% bằng thời gian. Firebase trả về Object Timestamp, phải dùng c.updatedAt.toMillis() để ép về số nguyên.

5. Kén Âm Thanh 3 Ống Tủy & Web Worker

Duy trì 3 thẻ Audio: mstq-silence (giữ mạng), mstq-alarm (chuông vật lý), và tts-audio (ép luồng Google) + Web Worker để đếm giờ ngầm xuyên qua Doze Mode.

6. Ép kiểu ID thành Chuỗi (String Casting)

Luôn bọc String(t.id) khi map/tìm kiếm mảng dữ liệu để tránh lỗi Javascript không so sánh được ID dạng Number (từ Local) và String (từ Firebase).

7. Tránh Tử Huyệt Visibility Deadlock

Tuyệt đối KHÔNG chặn hàm renderTasksOnly() bằng if (document.visibilityState === 'hidden'). Màn hình PC sẽ mù dữ liệu vĩnh viễn khi tab chạy ngầm.

Cấu Trúc Lưu Trữ (Storage Flow)

Mỗi hồ sơ sở hữu 4 Key độc lập trong LocalStorage. Dữ liệu trên Cloud lưu theo document LifeOS_Profiles/[tên-đăng-nhập].

LocalStorage Key / Cloud Field Mô tả cấu trúc
lifeos_v8_data_[tên]Mảng Nhiệm vụ (todos). Đã bọc bộ lọc tẩy rửa undefined trước khi đẩy lên Cloud.
lifeos_stats_v8_[tên]Object stats đếm Chuỗi kỷ luật (Ngọn lửa streak).
lifeos_v8_time_[tên]Timestamp (Integer) đồng bộ cập nhật CÙNG LÚC khi thao tác. Đối trọng so sánh chống Race Condition.
lifeos_v8_vault_[tên]Mảng VaultState.data (Kho lưu trữ, 2FA, Password).
