HỒ SƠ KIẾN TRÚC HỆ THỐNG (Architecture Profile)Đây là tài liệu kỹ thuật dành cho bạn để quản lý, bảo trì và phát triển dự án trên mọi nền tảng mà không sợ sai lệch.1. Thông tin cốt lõi (Core Stack)Giao diện & Cấu trúc: HTML5, TailwindCSS (via CDN), Phosphor Icons. Ứng dụng chạy theo chuẩn SPA (Single Page Application).Logic (Não bộ): Vanilla JavaScript (ES6+). Cấu trúc dạng Object Literals (VaultUI, VaultApp, FirebaseSync) giúp dễ dàng module hóa.Cơ sở dữ liệu (Database): * Layer 1 (Offline First): localStorage. Đảm bảo tốc độ truy xuất 0ms và khả năng hoạt động không cần mạng.Layer 2 (Cloud Sync): Firebase Firestore. Dùng thư viện tĩnh firebase-compat để tránh Crash Module.Bảo mật: Xác thực Firebase Anonymous (Ẩn danh dựa trên Device/Trình duyệt).2. Cấu trúc lưu trữ dữ liệu (Storage Flow)Mỗi người dùng (Profile) sẽ có 4 key độc lập trong LocalStorage và 4 mảng tương ứng trên Document Firestore:lifeos_v8_data_[tên]: Lưu mảng todos (Nhiệm vụ).lifeos_stats_v8_[tên]: Lưu mảng stats (Chuỗi ngày & kỷ luật).lifeos_v8_logs_[tên]: Lưu mảng sentinelLogs (Nhật ký cảnh báo).lifeos_v8_vault_[tên]: Lưu mảng VaultState.data (Kho lưu trữ).(Ví dụ: Dữ liệu của anh Xiêm sẽ lưu ở Cloud LifeOS_Profiles/xiem)3. Cơ chế đồng bộ thông minh (Smart Sync Mechanism)Khi có mạng (Online): Bất cứ khi nào bạn nhấn Thêm/Sửa/Xóa (ở Todo hoặc Vault), hệ thống gọi window.VaultStorageLayer.saveLocalOnly() để ghi ngay vào máy, sau đó gọi window.FirebaseSync.pushAll() để đẩy lên Cloud.Đồng bộ thiết bị khác: Firebase liên tục lắng nghe onSnapshot. Nếu thấy trên Cloud có dữ liệu mới (do thiết bị khác đẩy lên), nó sẽ kéo về, đè vào LocalStorage và window.renderTasksOnly() để cập nhật UI mà không làm tải lại trang.PHẦN 3: HƯỚNG DẪN SỬ DỤNG (User Manual)1.
