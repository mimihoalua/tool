1. Tab Nghe Nhạc (Web Audio Core)

Tử huyệt PWA & Service Worker Cache

Việc gọi localStorage.removeItem() và location.reload() là không đủ với PWA. Trình duyệt vẫn sẽ lấy code cũ từ Service Worker Storage. Để dọn rác triệt để, phải chọc thủng API caches:

if ('caches' in window) { caches.keys().then(names => Promise.all(names.map(name => caches.delete(name)))) .then(() => window.location.href = window.location.pathname + '?v=' + Date.now()); }

Quy tắc Event Bubbling (Lây lan sự kiện)

Các nút chức năng (Share, Download) nằm bên trong một khối Card bấm được (Thẻ bài hát). Bắt buộc bọc event.stopPropagation() và event.preventDefault() để tránh kích hoạt nhầm lệnh Play khi vừa ấn Share.

Bẫy Web Share API & Promise

  • Lỗi Mobile Webview: Không nhét thuộc tính text vào navigator.share. Zalo/FB sẽ nuốt lỗi AbortError. Chỉ truyền title và url.
  • Lời thề Bất đồng bộ: Lệnh Fallback Copy to Clipboard (navigator.clipboard.writeText) trả về Promise. Phải nối .then() mới được báo Toast "Thành công".

CORS & Caching Headers

Không tự ý nối Query String (như _cb=Date.now()) vào các public API (ví dụ Archive.org). Hành vi này kích hoạt Preflight OPTIONS request, dẫn đến việc bị chặn bởi chính sách CORS.

2. Cảnh Báo JS Silent Crash

Lỗi đứt gãy dây chuyền (N/A Profile):

Tuyệt đối KHÔNG bọc try/catch tổng vào các hàm khởi tạo biến Global hoặc cắt xén các hàm cơ sở (như setHtml). Nếu một hàm chết, toàn bộ code phía dưới sẽ ngừng chạy, biến PROFILES không được nạp, gây lỗi hiển thị N/A và treo vĩnh viễn màn hình đăng nhập.

3. Cơ Chế The Iron Lock

Chống Race Condition & Smart Fallback

Trong môi trường mạng, Snapshot từ Firebase có thể dội về đúng lúc thiết bị vừa gửi dữ liệu lên, gây tự xóa dữ liệu (Race Condition). Giải pháp:

  • Bật cờ window._pendingPush = true trong 1.5s khi đẩy dữ liệu.
  • Smart Fallback: Nếu Snapshot dội về có Timestamp cũ, bỏ qua. Nếu Timestamp MỚI HƠN, phá khóa Iron Lock và nhận dữ liệu ngay lập tức.

4. Báo Thức X-Quang & Ducking

Dynamic Audio Ducking

Hạ nhạc nền (Tab Music) xuống 20% khi báo thức kêu và tự động phục hồi 100% khi AI đọc xong, tránh âm thanh "đấm nhau".

JIT Pre-Caching

  • Dùng meta referrer="no-referrer" để bypass lỗi 403 Google Translate TTS.
  • Nạp trước âm thanh vào RAM 30 giây trước khi báo thức nổ để chống Doze Mode.
