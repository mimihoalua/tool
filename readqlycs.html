Bảng Phong Thần (Những lỗi cấm lặp lại)

1. Lỗi Form Reload (Trang tự F5 mất dữ liệu)

Bỏ quên e.preventDefault() ở thẻ <form id="form-pc">. Khi bấm Enter, trình duyệt tự động thực thi GET request làm reload toàn bộ trang web. Hậu quả: Dữ liệu bay hơi, đứt kết nối Firebase, Playwright chờ mòn mỏi 15s gây gãy đồng bộ.

Luôn gắn e.preventDefault() vào mọi sự kiện 'submit' của Form.

2. Cái chết của Nút Share (Web Share API)

Cố tỏ ra nguy hiểm khi nhét thêm thuộc tính text vào navigator.share({title, url}). Trình duyệt nhúng của Zalo/Facebook gặp text sẽ bị "ngáo", âm thầm nuốt lỗi và chớp tắt UI.

Đồng thời, hàm navigator.clipboard là một Promise. Bắt buộc phải dùng .then() và .catch() thay vì chạy đồng bộ.

3. Tẩy giun quên uống thuốc xổ (PWA Cache)

Lệnh location.reload() không thể xóa được bộ nhớ đệm HTTP của Service Worker. Để làm sạch App 100%, phải kết hợp 3 lệnh:

  • localStorage.clear()
  • caches.keys().then(k => caches.delete(k))
  • navigator.serviceWorker.getRegistrations().then(r => unregister)

4. Tử huyệt "N/A Profile" (JS Silent Crash)

Tuyệt đối không bọc try/catch bừa bãi vào mảng Global, không cắt xén các hàm cơ bản (vd: startBackgroundWorker). JS bị crash ở 1 dòng sẽ dừng toàn bộ luồng, khiến biến PROFILES không được nạp.

5. Định Vị Ảo (Playwright Evaluate Timeout)

Firebase có độ trễ ~250ms. Nếu dùng lệnh locator.evaluate(), Playwright sẽ kiểm tra DOM tức thời và báo lỗi ngay giây đầu tiên. Bắt buộc phải dùng wait_for_selector() để Polling nhẫn nại đợi Firebase cập nhật DOM.

Lõi Kỹ Thuật Sinh Tử

The Iron Lock (Chống Data Race)

Khi thiết bị đang Push dữ liệu lên Cloud, bật cờ window._pendingPush = true. Trạng thái này sẽ như một tấm khiên, từ chối mọi Snapshot dội về từ Firebase trong lúc mạng đang truyền tải, ngăn chặn việc dữ liệu cũ đè lên dữ liệu mới.

Vector Clock (toMillis)

Phân giải tranh chấp giữa PC và Mobile. Nếu localTime > cloudTime (do snapshot bị nghẽn mạng dội về chậm), thiết bị sẽ từ chối tải DOM mới, và tự động gọi lại pushAll() để đè ngược bản Local lên Cloud bảo vệ dữ liệu.

Hệ thống X-Quang Audio 3 Lớp

  • Mỏ Neo 30 phút: Phát ngầm silence_30min.mp3 để giữ WakeLock cho CPU, chống Doze Mode.
  • Ducking Nhạc Nền: Khi báo thức nổ, lưu lại volume hiện tại, bóp cổ nhạc nền xuống 20%. Đọc TTS xong nhả lại 100%.
  • JIT Pre-Caching: Ở mốc đếm ngược 30 giây cuối, ép thẻ Audio tải trước Link Google TTS vào RAM để vượt giới hạn mạng khóa màn hình.

Cẩm Nang Vận Hành 4 Tab

Tab 1: Nhiệm Vụ (NLP & Snooze)

Hệ thống NLP nhận diện cú pháp: hằng ngày lúc 14h30 ... !gấp. Chú ý: Nếu nhập giờ trong quá khứ của hôm nay, hệ thống sẽ báo động tức thì (không dời sang ngày mai).

Khi báo động nổ, nút Báo Lại (5 Phút) sẽ tính Date.now() + 300000 và lập tức Push lên Cloud để ghim đồng bộ.

Tab 2: Tập Trung (Zero CPU)

Thiết kế hoàn toàn bằng Vanilla JS (setInterval). Vì không bị ràng buộc bởi VDOM của React, bộ đếm có thể chạy mượt mà ngay cả khi document.visibilityState === 'hidden' mà không tốn tài nguyên Render.

Tab 3: Kho Lưu Trữ (3 Lớp Trích Xuất Data)

Để lấy dữ liệu mà không can thiệp phá hỏng kiến trúc hiện tại, QA có 3 cách:

  • UI Export: Bấm icon Tải xuống -> Sinh file .json.
  • Console: F12 gõ window.VaultStorageLayer.getData() (Mảng chuẩn).
  • Raw LocalStorage: F12 -> Application -> Key: lifeos_v8_vault_[name].

Tab 4: Nghe Nhạc Cả Ngày

Trình phát nằm ở Z-Index: 100 để luôn nổi. Tích hợp MediaSession API (điều khiển màn hình khóa). Dropdown Hẹn giờ tắt hoạt động độc lập giải phóng RAM khi hết giờ.

window.parseTaskNLP = (rawText) => {
    let text = rawText; let isDaily = false; let priority = false; let tags = []; let timeStr = null; let alarmTime = null;
    let dueDate = window.getIsoDate(); 
    let forceToday = false;

    if (text.match(/hằng ngày|mỗi ngày|hàng ngày/i)) { isDaily = true; text = text.replace(/hằng ngày|mỗi ngày|hàng ngày/gi, ''); }
    if (text.match(/!g[aâáàảãạ]p|!kh[aâáàảãạ]n|kh[aâáàảãạ]n c[aâáàảãạ]p/i)) { priority = true; text = text.replace(/!g[aâáàảãạ]p|!kh[aâáàảãạ]n|kh[aâáàảãạ]n c[aâáàảãạ]p/gi, ''); }
    const tagMatch = text.match(/#[\w_]+/g);
    if (tagMatch) { tags = tagMatch; tags.forEach(t => text = text.replace(t, '')); }

    let isTomorrow = false;
    if (text.match(/ngày mai|sáng mai|chiều mai|tối mai|\bmai\b/i) && !isDaily) { isTomorrow = true; text = text.replace(/ngày mai|sáng mai|chiều mai|tối mai|\bmai\b/gi, ''); }
    if (text.match(/\bnay\b|hôm nay/i)) { forceToday = true; text = text.replace(/\bnay\b|hôm nay/gi, ''); }

    const dateRegex = /\b(\d{1,2})[\/\-](\d{1,2})(?:[\/\-](\d{4}))?\b/;
    const dMatch = text.match(dateRegex);
    if(dMatch) {
        let day = parseInt(dMatch[1]), month = parseInt(dMatch[2]), year = dMatch[3] ? parseInt(dMatch[3]) : new Date().getFullYear();
        dueDate = `${year}-${String(month).padStart(2,'0')}-${String(day).padStart(2,'0')}`;
        text = text.replace(dMatch[0], '');
        forceToday = true; 
    }

    const timeRegex = /(?:lúc|vào lúc|vào|@)?\s*([0-2]?[0-9])(?:h|:|\s*giờ)\s*([0-5][0-9])?\s*(sáng|chiều|tối)?/i;
    const tMatch = text.match(timeRegex);
    if (tMatch) {
        let h = parseInt(tMatch[1]); let m = tMatch[2] ? parseInt(tMatch[2]) : 0; let ampm = tMatch[3] ? tMatch[3].toLowerCase() : '';
        if ((ampm === 'chiều' || ampm === 'tối') && h < 12) { h += 12; } else if (ampm === 'sáng' && h === 12) { h = 0; }
        timeStr = `${String(h).padStart(2, '0')}:${String(m).padStart(2, '0')}`;
        
        let now = new Date(); 
        let target;
        if(dueDate !== window.getIsoDate()) {
            let parts = dueDate.split('-'); target = new Date(parts[0], parseInt(parts[1])-1, parts[2], h, m, 0, 0);
        } else {
            target = new Date(now.getFullYear(), now.getMonth(), now.getDate(), h, m, 0, 0);
        }
        
        if (isTomorrow) {
            target.setDate(target.getDate() + 1);
            dueDate = window.getIsoDate(target);
        } else if (target.getTime() < now.getTime() && !forceToday && isDaily) {
            target.setDate(target.getDate() + 1);
            dueDate = window.getIsoDate(target);
        }
        
        alarmTime = target.getTime(); 
        text = text.replace(tMatch[0], '');
    }

    if (isTomorrow && !timeStr && !dMatch) {
        let target = new Date(); target.setDate(target.getDate() + 1);
        dueDate = window.getIsoDate(target);
    }

    return { text: text.replace(/\s+/g, ' ').replace(/^(lúc|vào lúc|vào)\s+/i, '').trim(), isDaily, priority, tags, timeStr, alarmTime, dueDate, alarmEnabled: true };
};

window.checkAlarms = () => {
    if(!window.todos || !window.todos.length) return;
    const nowMs = Date.now();
    const todayStr = window.getIsoDate();
    let hasAlert = false; let alarmTexts = []; let needsSync = false; let triggeredIds = [];
    
    window.todos.forEach(t => {
        if (t.isDaily && t.dueDate && t.dueDate < todayStr) {
            t.completed = false; t.alerted = false; t.dueDate = todayStr;
            if(t.alarmTime) {
                const oldDate = new Date(t.alarmTime); const newAlarm = new Date();
                newAlarm.setHours(oldDate.getHours(), oldDate.getMinutes(), 0, 0);
                if (newAlarm.getTime() <= nowMs) newAlarm.setDate(newAlarm.getDate() + 1);
                t.alarmTime = newAlarm.getTime();
            }
            needsSync = true;
        }
        
        if(!t.completed && t.alarmTime && t.alarmEnabled !== false && !t.alerted) {
            const timeDiff = t.alarmTime - nowMs;
            
            // JIT PRE-CACHING
            if (timeDiff > 0 && timeDiff <= 30000 && !window.preloadedTTS.has(t.id) && window.soundEnabled) {
                window.preloadedTTS.add(t.id);
                const c = el('tts-audio');
                if (c) {
                    c.src = `https://translate.googleapis.com/translate_tts?ie=UTF-8&tl=vi&client=gtx&q=${encodeURIComponent(t.text)}`;
                    c.load(); 
                }
            }
            
            if (timeDiff <= 0 && !window.notifiedTasks.has(String(t.id))) {
                window.notifiedTasks.add(String(t.id));
                hasAlert = true; 
                alarmTexts.push(t.text); triggeredIds.push(String(t.id));
            }
        }
    });
    
    if(needsSync) { window.saveLocalTodos(); window.renderTasksOnly(); } 
    if(hasAlert) { window.triggerGlobalAlarm(triggeredIds, alarmTexts.join(' + ')); }
};

window.syncManualDateToInput = (inputEl, targetId) => {
    if(!inputEl.value) return;

    const dateStr = `${String(d.getDate()).padStart(2,'0')}/${String(d.getMonth()+1).padStart(2,'0')}/${d.getFullYear()}`;
    const timeStr = ` lúc ${String(d.getHours()).padStart(2,'0')}h${String(d.getMinutes()).padStart(2,'0')}`;
    
    const textInput = el(targetId);
    if(textInput) {
        let v = textInput.value;

            write_log(f"{prefix} Bị chặn tải link MP3, Fallback kích hoạt!", color=Fore.YELLOW)
        else:
            write_log(f"{prefix} ERROR/CRASH {details}", color=Fore.RED)
    elif evt == "ended":
        write_log(f"{prefix} ENDED {details}", color=Fore.MAGENTA)
    elif evt not in ["timeupdate", "pause", "waiting", "loadstart", "loadeddata", "loadedmetadata"]:
        write_log(f"{prefix} {evt.upper()} {details}", color=Fore.CYAN)

def inject_super_debug(page: Page) -> None:
    page.evaluate("""() => {
        const attachAudioMonitors = () => {
            const events = ['play', 'playing', 'pause', 'waiting', 'error', 'ended', 'loadstart', 'canplay'];
            document.querySelectorAll('audio').forEach(audio => {
                if(audio.dataset.monitored) return;
                audio.dataset.monitored = 'true';
                events.forEach(evt => {
                    audio.addEventListener(evt, e => {
                        if (window.pyAudioSensor) {
                            window.pyAudioSensor({
                                event: e.type, id: e.target.id || 'Unnamed-Audio', src: e.target.src || 'none',
                                time: (!isNaN(e.target.currentTime) ? e.target.currentTime : 0), ready: e.target.readyState
                            });
                        }
                    });
                });
            });
        };
        attachAudioMonitors();
        new MutationObserver(attachAudioMonitors).observe(document.body, { childList: true, subtree: true });
    }""")

class DeviceTelemetry:

    def attach_sensors(self, page: Page) -> None:
        def log_console(msg):
            msg_type = msg.type.upper()

            if "tailwindcss" not in msg.text:

        page.on("console", log_console)
