5. Bảng Phong Thần (5 Gáo Nước Lạnh)

1. Lỗi Form Reload (Trang tự F5 mất dữ liệu)

Bỏ quên e.preventDefault() ở thẻ <form id="form-pc">. Khi bấm Enter, trình duyệt tự động thực thi GET request làm reload toàn bộ trang web. Hậu quả: Dữ liệu bay hơi, đứt kết nối Firebase.

Luôn gắn e.preventDefault() vào mọi sự kiện 'submit'.

2. Bệnh "Hồn Trương Ba, Da Hàng Thịt" (PWA Manifest)

Dùng chung file manifest.json của dự án cũ (MiMiFlower Shop) vào dự án mới. Hậu quả: Cài LifeOS nhưng Icon và Tên hiển thị là Shop Hoa, bấm vào mở nhầm trang đích do sai start_url.

Mỗi PWA phải có 1 manifest độc lập, start_url tuyệt đối.

3. Bom hạt nhân Cache (Tẩy giun quên thuốc xổ)

Dùng localStorage.clear() để dọn rác nhạc, kết quả là quét sạch luôn Nhiệm vụ và Vault của người dùng. Cần phải kết hợp "Dao mổ" (Xóa đúng Key nhạc) và "Máy hút bụi" (Xóa Caches API & Service Worker).

4. Cái chết của Nút Share & Tàng hình DOM

Truyền sai thuộc tính vào Web Share API làm Zalo/FB nuốt lỗi. Bỏ qua Promise của Clipboard API làm iOS chặn lệnh. Đồng thời, khi chuyển từ React sang Vanilla JS, quên đổi display: block làm Mini Player tàng hình vĩnh viễn.

5. Định Vị Ảo (Playwright Evaluate Timeout)

Firebase có độ trễ ~250ms. Nếu dùng lệnh locator.evaluate(), Playwright sẽ kiểm tra DOM tức thời và báo lỗi. Bắt buộc phải dùng wait_for_selector() để nhẫn nại đợi Firebase cập nhật.

6. 7 Quy Tắc Vàng (Tuyệt đối không vi phạm)

Bất kỳ ai chạm vào mã nguồn đều phải thuộc lòng 7 nguyên tắc sống còn sau đây. Đây là kết quả của hàng chục giờ debug.

1. Pháo Đài Offline (Chống ORB/404)

Đường dẫn tương đối ./ trên GitHub Pages gây lỗi tải nhầm trang 404 HTML thành file JS. Bắt buộc dùng đường dẫn tuyệt đối /tool/filename.js.

2. Thanh trừng "Undefined"

Firestore sẽ ném lỗi Unsupported field value: undefined. Bắt buộc phải chạy vòng lặp delete cleanT[key] trước khi set().

3. Cấm Push Lúc Khởi Động

Tuyệt đối KHÔNG ĐƯỢC gọi this.pushAll() trong hàm init() để tránh ghi đè dữ liệu Cloud bằng dữ liệu cũ ở Local.

4. Đồng Hồ Vector & toMillis()

Firebase trả về Object Timestamp, bắt buộc phải dùng c.updatedAt.toMillis() để ép về số nguyên rồi mới so sánh.

5. Kén Âm Thanh 3 Ống Tủy

Duy trì 3 thẻ Audio: mstq-silence (giữ mạng), mstq-alarm (chuông vật lý), và tts-audio (Google Translate) + Web Worker.

6. Ép kiểu ID thành Chuỗi (String Casting)

Luôn bọc String(t.id) khi map mảng dữ liệu để tránh lỗi Javascript không so sánh được Number và String.

7. Tránh Tử Huyệt Visibility Deadlock

Tuyệt đối KHÔNG chặn hàm renderTasksOnly() bằng if (document.visibilityState === 'hidden'). Màn hình PC sẽ mù dữ liệu vĩnh viễn khi tab chạy ngầm.

Dynamic Audio Ducking
