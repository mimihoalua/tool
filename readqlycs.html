Quy tắc Vàng (Không thể vi phạm)

Bất kỳ AI hay lập trình viên nào chỉnh sửa mã nguồn V12 đều phải tuân thủ tuyệt đối 3 nguyên tắc Lập trình phòng ngự (Defensive Programming) sau đây để hệ thống không bao giờ bị Crash hay Đơ màn hình:

1 Luôn ép kiểu ID thành Chuỗi (String Casting)

Lỗi đơ nút Sửa/Xóa sinh ra do JS nhầm lẫn giữa kiểu Number và String từ Firebase trả về. Khi viết hàm tìm kiếm, Sửa hoặc Xóa, BẮT BUỘC phải bọc String() cho ID.

// ❌ SAI (Gây đơ Web vì sai kiểu dữ liệu):
const item = data.find(x => x.id === id);

// ✅ ĐÚNG VÀ BẮT BUỘC:
const item = data.find(x => String(x.id) === String(id));

2 Bọc thép tương tác DOM (Safe DOM Helpers)

Không gọi trực tiếp document.getElementById(id).value vì nếu DOM chưa tải kịp sẽ báo lỗi Null làm sập toàn bộ JavaScript. Phải dùng hàm Helper có sẵn.

// Helper bọc thép đã định nghĩa ở đầu File:
const setTxt = (id, text) => { const e = document.getElementById(id); if(e) e.textContent = text; };
const getVal = (id) => { const e = document.getElementById(id); return e ? e.value : ''; };
const showFlex = (id) => { const e = document.getElementById(id); if(e) { e.classList.remove('hidden'); e.style.display='flex'; } };

3 Cấu trúc Modal an toàn (No Absolute Layout)

Không bao giờ dùng thuộc tính CSS position: absolute cho các form Modal. Nếu dùng, khi bàn phím điện thoại nảy lên, form sẽ bị văng khỏi màn hình che mất nút "Lưu". Phải dùng Flexbox chuẩn của Tailwind:

<!-- Cấu trúc chuẩn chống vỡ Layout -->
class="fixed inset-0 flex items-center justify-center"
class="max-h-[90vh] overflow-y-auto"

Kiến trúc Cốt lõi

Giao diện (UI) SPA

Thiết kế chuẩn SPA (Single Page Application) bằng HTML5, TailwindCSS. Hoạt động mượt mà, chuyển tab tức thời mà không cần reload trang.

Logic (Não bộ)

Sử dụng Vanilla JavaScript ES6+. Cấu trúc module (VaultUI, VaultApp, FirebaseSync) được gắn thẳng vào biến toàn cục window để chống thất thoát hàm.

Cơ sở dữ liệu (2 Lớp)

  • Lớp 1 (Offline): localStorage - Lưu tại máy, tốc độ 0ms.
  • Lớp 2 (Cloud): Thư viện firebase-compat đồng bộ Real-time.

Cơ chế Auto-Heal (Tự chữa lành)

Nếu Cache lưu phiên đăng nhập cũ không còn hợp lệ, App tự nhận diện lỗi, xóa sạch rác và buộc quay về màn hình đăng nhập thay vì sập trắng trang.

2. Cấu trúc Lưu trữ (Storage Flow)

Mỗi hồ sơ (Profile) sở hữu 4 Key độc lập trong bộ nhớ. Dữ liệu trên Cloud sẽ được tổ chức theo đường dẫn LifeOS_Profiles/[tên-đăng-nhập].

Tên Key (LocalStorage / Field) Nội dung lưu trữ
lifeos_v8_data_[tên] Mảng todos (Nhiệm vụ, Checkbox).
lifeos_stats_v8_[tên] Object stats (Đếm chuỗi ngày kỷ luật).
lifeos_v8_logs_[tên] Mảng sentinelLogs (Nhật ký cảnh báo AI).
lifeos_v8_vault_[tên] Mảng VaultState.data (Kho lưu trữ / Password).

3. Đồng bộ Thông minh (Smart Sync)

Luồng Đẩy (Online Push)

  • 1 Người dùng bấm Lưu/Xóa.
  • 2
    saveLocalOnly() ghi vào máy ngay lập tức (0.01s). Giao diện đổi ngay lập tức.
  • 3
    Gọi ngầm FirebaseSync.pushAll() đẩy JSON lên Firestore. (Nếu lỗi mạng, tự động thử lại sau).

Luồng Kéo (Realtime Pull)

  • 1 Firebase dùng onSnapshot() nằm vùng.
  • 2 Thiết bị khác đẩy dữ liệu lên Cloud.
  • 3
    Kích hoạt tải dữ liệu mới về, đè vào LocalStorage và chạy renderTasksOnly() cập nhật UI không cần F5.

Cẩm Nang Vận Hành

4.1 Quản lý Hồ sơ (Profile)

Danh sách 5 thành viên được định nghĩa cứng trong file HTML tại biến window.PROFILES:

  • Admin admin
  • Xiêm a
  • Thành a
  • Thắm a
  • Phúc a

Đặc quyền Quản trị:

Chỉ khi đăng nhập tài khoản Admin, bấm vào Menu Góc Phải, bạn mới thấy danh sách xổ xuống của những người khác để xem/sửa chéo dữ liệu.

Mật khẩu vạn năng (Master PIN) là 9999 dùng được cho mọi tài khoản để phá khóa trong trường hợp quên.

4.2 Kho lưu trữ Đa năng (Vault)

Hệ thống hỗ trợ tự động bóc tách (Auto-Parse). Để kích hoạt, bạn gõ chính xác các cú pháp sau ở phần đầu dòng của ô "Nội dung dữ liệu":

Tài khoản: admin@gmail.com → Hiện icon user + nút Copy
Mật khẩu: 123456 → Tự ẩn dạng dấu chấm ••• + nút Mắt + Copy
2FA: JBSWY3DPEHPK3PXP → Tự tạo Đồng hồ OTP chạy 30 giây
Link: https://facebook.com → Chữ màu xanh, click vào mở URL

Dòng chữ bình thường dưới cùng sẽ tự động gom thành ghi chú...
Mẹo: Nút "Tạo MK an toàn" trong bảng nhập tự sinh chuỗi ngẫu nhiên kèm rung Haptic.

4.3 Todo & Sentinel AI (Báo thức)

Thêm nhanh (Quick Add):

Thay vì click chọn rườm rà, bạn chỉ cần gõ vào thanh nhập liệu (Smart Input):

@14h !gấp #hoc_tap Đọc chương 1

Hệ thống tự bóc tách ra: Giờ (14:00), Mức độ (Khẩn cấp), Tag (#hoc_tap).

Haptic & Voice Guard

  • Cảm biến rung (Haptic): Thao tác Thêm, Sửa, Xóa, Bấm giờ, Vuốt đều kích hoạt Rung vật lý tạo cảm giác chân thực.
  • Voice Guard: Trợ lý AI sẽ đọc to tiếng Việt "Tuyệt vời", "Đã lưu", hoặc cảnh báo khi hết giờ (Đảm bảo điện thoại không tắt tiếng).

4.4 Chuyển thiết bị & Cứu dữ liệu JSON

  • Đăng nhập máy mới (Tự động):

    Vào link trang web trên thiết bị mới, chọn tên Profile, nhập mã PIN. Dữ liệu từ Firebase Cloud sẽ tự động tải xuống LocalStorage và hiển thị trong 2 giây.

  • Cứu dữ liệu bằng file JSON (Thủ công):

    Vào Kho lưu trữ → Bấm nút Tải lên → Chọn file JSON cũ. Sau khi nạp xong, hãy tạo 1 ghi chú mới bất kỳ, thao tác này sẽ kích hoạt lệnh pushAll() đẩy đè file JSON đó ngược lên Cloud.
