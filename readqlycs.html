Cơ sở dữ liệu

Kiến trúc 2 lớp đảm bảo tốc độ và độ tin cậy.

L1

Offline First — localStorage

Tốc độ truy xuất 0ms, hoạt động không cần mạng

L2

Cloud Sync — Firebase Firestore

Dùng firebase-compat, tránh Crash Module

Bảo mật

Xác thực Firebase Anonymous — ẩn danh dựa trên Device/Trình duyệt.

Mỗi thiết bị tự động có ID riêng, không cần đăng ký tài khoản

Phần 2

Cấu trúc lưu trữ dữ liệu

Mỗi người dùng (Profile) sở hữu 4 key độc lập trong LocalStorage, tương ứng 4 mảng trên Firestore.

lifeos_v8_data_[tên]

Lưu mảng todos — Nhiệm vụ

localStorage
Firestore Array

lifeos_stats_v8_[tên]

Lưu mảng stats — Chuỗi ngày & kỷ luật

localStorage
Firestore Array

lifeos_v8_logs_[tên]

Lưu mảng sentinelLogs — Nhật ký cảnh báo

localStorage
Firestore Array

lifeos_v8_vault_[tên]

Lưu mảng VaultState.data — Kho lưu trữ

localStorage
Firestore Array
Ví dụ

Dữ liệu của anh Xiêm sẽ lưu tại Cloud path:

LifeOS_Profiles/xiem
├── data // todos
├── stats // kỷ luật
├── sentinelLogs // nhật ký
└── vaultData // kho lưu trữ

4.1

Quản lý Profile

Khi vào App, bạn chọn tên của mình từ danh sách Profile.

Quản trị viên (Admin) có quyền truy cập danh sách ở góc phải trên cùng → Cho phép xem/sửa chéo dữ liệu của các thành viên khác (Thành, Thắm, Phúc...) ngay lập tức.

Mật khẩu mặc định

Admin

admin

Thành viên

a

Có thể sửa trong biến window.PROFILES ở đầu file JS.

4.2

Kho lưu trữ Đa năng & Smart Input

Tính năng mạnh nhất của V8.8

Hỗ trợ 2 chế độ nhập liệu: nhập thô và nhập thông minh (Auto Parse).

Nhập thô

Gõ bất cứ đoạn văn bản, ghi chú nào vào khung "Nội dung dữ liệu" và bấm Lưu.

Nhập thông minh (Auto Parse)

Gõ theo cú pháp ở đầu các dòng để hệ thống tự nhận diện:

Tài khoản: → Hiển thị nút copy
Mật khẩu: → Ẩn/hiện + nút copy
2FA: → Mã OTP Live (30s)
Link: → Click mở trực tiếp

Ví dụ nhập thông minh

Tài khoản: admin@gmail.com
Mật khẩu: 123456
2FA: JBSWY3DPEHPK3PXP // → Tự tạo mã OTP Live chạy 30s
Link: https://facebook.com
